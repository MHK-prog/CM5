# معلم یار دماوند

اپ اندرویدی مستقل برای مدیریت کلاس‌ها و صدور کارنامه‌ی زبان‌آموزان. رابط برنامه داخل APK بسته‌بندی شده و کارهای روزمره به سایت نیاز ندارند. اتصال اینترنت فقط برای بررسی انتشار نسخه‌ی جدید استفاده می‌شود.

افزودن و ویرایش زبان‌آموز از فرم پروفایل انجام می‌شود و عکس‌ها با نسبت ۳:۴ ذخیره می‌شوند. کارنامه‌های یک کلاس در یک PDF چندصفحه‌ای A5 ذخیره می‌شوند؛ برای هر زبان‌آموز یک صفحه در نظر گرفته شده است. PDF از HTML ساخته می‌شود و فایل منبع HTML نیز جداگانه قابل ذخیره است. امضای مدرس در کارنامه نمایش داده نمی‌شود.

در بخش پشتیبان‌گیری، برنامه یک پوشه شامل `CM5_backup.json` و عکس‌های جداگانه در زیرپوشه‌ی `images` می‌سازد. بازیابی پوشه‌ی کامل، JSON و عکس‌ها را با هم برمی‌گرداند. وارد کردن فایل JSON نسخه‌ی CM 4.5.2 نیز پشتیبانی می‌شود.

## ساخت APK در ویندوز

1. JDK 17 یا جدیدتر و Android SDK نصب باشند؛ مسیر SDK در `local.properties` تنظیم شود (این فایل در Git قرار نمی‌گیرد). در این رایانه، `JAVA_HOME` باید به JDK نصب‌شده اشاره کند.
2. در PowerShell از ریشه‌ی پروژه اجرا کنید:

   ```powershell
   $env:JAVA_HOME = 'C:\Program Files\Java\jdk-27'
   .\gradlew.bat assembleDebug
   ```

3. APK آزمایشی در `app\build\outputs\apk\debug\app-debug.apk` ساخته می‌شود.

## انتشار نسخه‌ی امضاشده

فایل keystore را به مخزن اضافه نکنید. آن را به Base64 تبدیل و در **Settings → Secrets and variables → Actions** به‌عنوان این چهار Repository Secret ذخیره کنید:

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

از **Actions → Build and publish signed Maallem Yar Damavand APK → Run workflow** گردش‌کار انتشار را دستی اجرا کنید. گردش‌کار APK امضاشده را به artifact همان اجرا و به GitHub Release پیوست می‌کند. برنامه در شروع اجرا و با دکمه‌ی «بررسی نسخه جدید برنامه» انتشار جدید را بررسی می‌کند و لینک دریافت APK را نشان می‌دهد.

برای تبدیل فایل کلید به Base64 در PowerShell ویندوز:

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("C:\path\to\release-key.jks")) | Set-Clipboard
```

## داده‌ها

اطلاعات برنامه روی دستگاه ذخیره می‌شود. از صفحه‌ی پشتیبان‌گیری می‌توان همه‌ی کلاس‌ها، مشخصات، نمره‌های کارنامه و تصاویر را در قالب پوشه‌ی قابل‌دسترسی ذخیره یا بازیابی کرد. اطلاعات نمرات روزانه و توضیح سوپروایزر وارد این برنامه نمی‌شوند.
